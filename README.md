One satirical sentence about lawmakers who regulate AI, crypto and the internet but cannot convert a file to PDF, written by a program. The line reads:

> She wrote the 400-page bill regulating AI, crypto, and the internet, then emailed her staff a file named FINAL_final_v2 and asked them to turn it into a PDF.

The joke sets up the lawmaker's authority — a 400-page bill she wrote — then undercuts it with the file she cannot convert, landing the punch on the last words.
